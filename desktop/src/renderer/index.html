Adult & web filter

Makes your browsers use family-safe DNS (Cloudflare for Families) and forces Google SafeSearch on. It doesn't change your PC's network settings, so it can't slow down or cut off the internet. Locked by Strict Mode when it's on.

Enforced by the AppBlocker browser extension in Chromium browsers (Chrome, Edge, Brave, Vivaldi, Opera). Browsers that can't run the extension (Firefox, Safari, Tor…) are closed while this is on, so the allow-list can't be skipped. Non-browser apps are unaffected.

Strict Mode (all blocks)

While on, block lists can't be turned off or deleted, the adult/web filter can't be loosened, and closing the window keeps everything running in the background. This is the big lock over everything; each block list and the filter can also have their OWN lock.

Weekly unlock window

Pick the one short window each week when Strict Mode and any scheduled sign-out can be turned off. Everything stays locked the rest of the week. Minimum 1 minute. While this is on it's your guaranteed way out, so your block schedules are allowed to cover the whole day (00:00-23:59).

Scheduled Sign-Out (Windows account)

On the schedule you set, the chosen Windows account is signed out on sight — it can't be used at all. Other accounts still work. It stays signed out until your weekly unlock window. Use a separate account from the one that manages AppBlocker.

Settings

⚠ You're running as an Administrator

AppBlocker is much stronger when your everyday account is a Standard user, with a separate Administrator account you only use when needed. As an admin, you can undo the blocks yourself — as a standard user you can't (no editing the hosts file, no Safe Mode, no removing the extension).

You keep admin power either way: from a standard account, right-click any installer or dev tool → Run as administrator and enter the admin password. Your coding still works; the blocks just can't be casually bypassed.

  1. Open Windows user accounts (button below).
  2. Add a new account → make it an Administrator (give it a password you keep separate).
  3. Change your daily account to Standard user.
  4. Sign in to your Standard account for everyday use.

Browser extension

Websites are blocked inside the browser by the AppBlocker extension (encrypted DNS makes the hosts file alone unreliable). Once you publish it to the Chrome Web Store and Firefox Add-ons, it installs itself silently on Chrome, Edge, Brave and Firefox and can't be removed — see PUBLISHING.md (packages are in the dist-store folder).

For testing before publishing: Chrome/Brave → chrome://extensions → Developer mode → Load unpacked → src\extension. Firefox → about:debugging → Load Temporary Add-on → src\extension-firefox\manifest.json. This line turns green when connected.

Drive encryption (recommended hardening)

The strongest honest protection against someone wiping AppBlocker from a recovery command prompt is BitLocker drive encryption — booting into a recovery shell then requires your 48-digit recovery key. Unlike disabling Windows recovery, it keeps your PC fully recoverable.

Important: save your recovery key when Windows prompts you (to your Microsoft account, a file, or print it). If you lose it and forget your PIN, your data is unrecoverable — so Windows, not this app, walks you through turning it on.

Recovery-key vault (so you never lose it)

Paste your 48-digit BitLocker recovery key here and AppBlocker keeps it safe. It's hidden while Strict Mode is on and shown again once Strict Mode is off — so it can't be used to bypass the app mid-lock, but it's never lost. Stored locally on this PC only.

Or upload the recovery-key file Windows gave you (a .pdf or .txt). It's kept with your key and only opens when Strict Mode is off.

How it works

Block-list websites are blocked system-wide via the hosts file (all browsers), including their mobile and app subdomains (e.g. youtube.com also covers m.youtube.com, youtu.be and YouTube's video feeds). Apps are closed automatically when they run. The web allow-list uses the AppBlocker browser extension plus closing unprotected browsers. Editing the hosts file needs administrator rights, so run the app as admin. See the README for the honest limits and the uninstall-window rule (every schedule must leave at least one free minute a week).

Before you start — how AppBlocker protects itself

AppBlocker is a commitment tool. So it can't be casually bypassed, while Strict Mode is active it will, on Windows:

  • Block Safe Mode for standard (non-administrator) accounts.
  • Protect its own files so they can't be deleted while locked.
  • Keep running in the background and restart itself if closed.
  • Install a browser extension (Chrome/Edge/Brave/Firefox) that can't be removed while active.

All of this automatically releases during your weekly buffer window — the time you set when Strict Mode can be turned off. That window is when the app can be removed. Windows' own recovery (Reset / repair) is never disabled, and an administrator can always remove the app.

For the Safe-Mode protection to work, use a Standard user account for daily use, with a separate Administrator account.
